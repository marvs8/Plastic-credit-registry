# Governance Notes

This file captures the governance model for the registry.

## Governance Phases

- Phase 1 — Curated governance by founding team
- Phase 2 — Multi-sig council governance
- Phase 3 — Optional token-weighted governance

## Upgrade Safety

The registry should use a governance-controlled upgrade path with a time delay and clear audit trail.

## Participant Roles

- Issuers / validators
- Collectors / recyclers
- Buyers / retirees
- Auditor and compliance council
