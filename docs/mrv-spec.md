# MRV Specification

This file is a placeholder for the Measurement, Reporting, and Verification specification.

## Purpose

The MRV spec will define how off-chain proof bundles are constructed, hashed, and anchored on-chain.

## Key Concepts

- Proof bundle structure
- GPS and timestamp validation
- Weight measurement validation
- Collector and facility credential verification
- Duplicate submission prevention
- Off-chain storage and proof hash anchoring
